# 地面颜色属性

`FloorAttributes` 是共享CPU状态，使用标准容器和拥有所有权的字符串、回调，不依赖JNI、libnx、RenderWare设备或旧VC6容器布局。原PC包装和移植运行时共用 `UpdateFloorColorSample`，来源为游戏函数0x420BD0；声音表也只有一份。

## 数据与规则

P4CL v2保留原DFF三顶点的RGBA字节，顺序为解析后的a、b、c，不能把DFF流中的材质字段当作顶点索引。颜色来自几何体预光照数组，未经贴图、光照或浮点颜色往返。v1缓存缺少属性时明确拒绝；v2明确标记无预光照时按原函数直接返回，不生成白色属性。

采样先强制alpha为255，再转换成原D3D9格式8888的颜色标识（AARRGGBB）。这是数据编码适配，不实现RenderWare私有设备转换器；依据为已匹配SDK的0x777D70格式0x500分支及既有像素转换测试。原输入DWORD低字节为R，两种字节排列不能混用。

按原次序选择与current_color不同的二同色多数；没有多数时沿用current_color。Apply先更新声音路径，调用全部匹配回调；没有匹配时调用current_color对应的回调。0x420D90本身不改current_color或previous_color。随后从原alpha取二同值，否则使用fallback_alpha，保留原返回值的特殊位模式及回调先于alpha更新的顺序。

温度颜色选择复用0x5B4900：匹配五项中第一项，缺失保持旧选择。安卓绑定四个原温度色及初始current_color；此模块只实现地面选择回调。温度计时、启用、生命/真气变化及HUD尚未接通，不能据此声称完整温度玩法可用。

## N01与位置流程

原N01地面105个三角形的颜色均为RGBA DWORD `0xff003399`。出生点命中82，采样标识为 `0xff993300`，对应 `gamedata\palSound\WF013.wav`，alpha255。该颜色无温度直接注册项，按原规则调用初始黑色回调，温度选择为4；current_color仍为 `0xff000000`。这里只选择脚步声路径，没有实际播放脚步音效。

位置服务250更新同一地面对象。`floor-attributes-probe.json`保存调用时快照，`status.json`记录实时状态，用于检查EGL恢复不改变属性或重复回调。

目录由安卓应用创建，验证器先检查用户场景包SHA256及路径访问权限，再开始影片。已有ADB创建的目录需要先修复其所有者/访问权限；不将无法打开的文件当作成员不存在。

小地图分支独立于颜色：安卓直接查询用户 `scenedata.cpk` 的 `Q01\N01\MiniMap.df` 和 `PALWorld/q01.cpk` 的 `N01\MiniMap.df`。两者均缺失，并确认同前缀的N01_floor.dff存在后，采用0x40E210无活动图标的返回分支。有地图层的场景仍明确失败，未实现地图纹理/揭雾。
