# 怪物路径逐帧移动

MonsterMovement已连接原端点辅助对象的转向、候选球体响应、邻居避让、路径投影、物理积分和空间位置通知，供Android/Switch共用。同一服务现支持端点表842898（行为0/1）和随机表842AE8（行为3），见[随机逐帧移动](MONSTER_RANDOM_MOVEMENT.md)；本页说明端点分支。尚未接入ChapterHost、动画回写、完整调度或战斗；原地面/角色变换独立适配见[地面与角色回写](MONSTER_PATH_ORIENTATION.md)，非空怪物场景门禁保留。

## 接口与顺序

Update接收MonsterHelperHandle、实际有序障碍列表和秒数。障碍记录保留原首word、半径和中心；调用方必须显式传入，不提供默认空碰撞后备。临时候选token只在本帧障碍接口内有效，与世界句柄分开，不编码宿主指针。邻居与候选token缓冲复用容量。

组合复用42A760、42AB30、42C220、42BBD0、42B940/42BAD0和共享物理核心。已在IDA复核主调用顺序及碰撞分支：候选碰撞 → 无响应时邻居查询 → 可选避让/漂移/路径修正 → 积分 → 端点换向 → 空间通知。邻居保持原桶/链顺序，世界不排除自己，由原复杂碰撞函数跳过自己。

42AB30先取slot10前向量，不能误改成角色位置。路径投影回调单独实现，因为它需要slot18位置。投影返回的time实际是管道外带符号距离；保留原名与分支规则，不当作碰撞秒数。路径查询继续转发给ScenePathways，不在只读路径图像中伪造暂存字段。

碰撞过程只回写wander及两个投影向量（words13..20）；方向通知直接作用于真实辅助对象。物理积分只写186字节公共前缀，保留端点尾部。无路径时原函数只清B9，不取随机、不积分、不通知。

世界必须比移动服务活得更久。单游戏线程，禁止重入；错误句柄、表类型、路径、关联归属、帧时间或候选数值明确失败。异常可能留下已消耗随机或部分帧状态，调用方应停止并重建；不假装事务回滚。所有构造/恢复/移动必须使用同一实际共享随机服务。

## 验证与边界

- 主机与安卓模拟器：生成路径2400帧往返、3次换向；静态候选最早命中、近距分离、相向运动预测及投影向量回写、unclamped漂移、无路径、无效参数/归属、随机回调重入与删除后调用。
- 原M01/1三只、M02/1四只路径怪物分别连续600帧：辅助位置、前向、速度、请求向量、方向、最终字段和统计的主机/安卓完整报告一致；关闭后数值块为0。
- Win32隔离探针复用原native适配器，在同样生成路径上完成2400帧及三类碰撞通知，范围与换向数一致。隔离探针直接调用帧服务，未验证完整native场景管理器或原EXE数值等价。

原资源探针使用受控随机、新建行为内存、模型绑定半径和显式空静态候选列表；没有地面修正、角色回写、真实障碍收集或剧情验收。生成路径会越过端点后再返回，保留原算法结果，不以几何截断冒充路径跟随。

Android双ABI公共库与Switch完整ELF/NRO构建通过。Switch首轮因GCC class-memaccess严格检查失败，改为带边界检查的字节视图拷贝后通过；未在Switch运行本轮探针。
