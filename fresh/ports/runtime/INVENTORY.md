# 背包与脚本增删物品

已接服务98/99（giAddProperty/giDelProperty），供取弓及后续剧情使用；尚未在真实剧情中验收。

## 共用原规则

IDA复核5D46F0、4C7000、4C71D0后，保留ScriptInventoryChange与数量/序号/最近获得规则。数量增加上限99，负数转为反向操作；零数量也按原规则创建记录；既有记录保留序号，新记录从1递增。数量相加后保留原32位回绕及有符号比较。原INT_MIN互相反向递归分支仍未扩展支持，不以此测试一般负数兼容性。

InventoryItemChanges从旧记录存储中抽出，旧InventoryItemCollection经窄适配器调用同一实现；便携Inventory使用现代vector/set，不模拟VC6私有STL布局。最近获得去重并保留至多六项，删除用尽记录时清除最近列表，但已见物品集合保留。

Property定义现从原CPK解析ID、TYPE、PA_NAME及六项文本：说明、属性、图标、模型、贴图和附加特效名。使用效果、模型/特效展示和战斗消费另待接入。装备仍走现有PlayerEquipment，不把普通物品和装备记录混为一体。

## 原资源与提示

章节宿主现在直接从用户 database.cpk 在内存解析 Property 和 GameString，原 CP936 名称及文字转为 UTF8。P4PI 和 P4GS 文件仅供旧版和独立测试；新路径的246条物品定义及251/252文字已与原缓存对照，尚未设备实测。

原脚本处理器先检查定义并改变背包，再按参数生成提示；格式只接受原%s/%d及%%。提示显示请求的数量，保持原规则，不用背包上限替换显示数量。格式或显示失败不回滚此前已发生的物品改变，文本临时所有者仍清理。

提示复用HintWindow布局、字体测量与1秒关闭；获得/失去分别使用原WA06/WA07，经现有平台音频队列。富文本复用对白颜色解析，两平台消费相同Unicode范围；原br标签转为换行。独立安卓预览不播放音效，也不修改真实章节背包。
