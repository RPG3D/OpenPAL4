# 空闲角色控制器

`ActorController` 完成NewGame需要的空闲初始化：释放旧资源 → 重置输入/运动/查询状态 → 装载原JDumy → 注册FL/FR地面分类入口。共享C++不保存原虚表、函数地址或32位指针。

## 资源与状态

```powershell
pwsh -File fresh/ports/android/android-dev.ps1 prepare-controller
```

输入为原 `palobject/JDumy/JDumy.dff` 和同目录贴图，输出 `assets/controllers/JDumy.p4a` 与来源清单。原资源包含3个骨架节点、48个展开顶点、16个三角形；初始化时实际读取并采样绑定姿态，独立持有CPU资源，不加入可见世界。

直接核对IDA：`423660`构造、`4238B0`初始化、`423980`关闭、`4225E0`装载JDumy、`425300`地面分类。初始运动未激活、无待处理目标、到达标记为真；输入模式/事件模式为1。NewGame先执行关闭，因此初始化完成时控制器仍未启用、没有选中的玩家；这些状态应由场景脚本后续设置。

输入速度保留原浮点位模式 `4329e666/42fdcccd`。转向、竖直和水平比例分别为 `270/width`、`40/height`、`120/width`；安卓使用本次NewGame启动时的绘制尺寸。非法尺寸、缺失或损坏的JDumy均失败，不保留半初始化资源。取消NewGame时释放控制器和四槽玩家。

## FL/FR回调

`425300`虽然旧名含FloorSound，实际按WF地面名称选择脚底特效类别。PC与跨平台共用 `floor_effect_kind.h`，保留大小写、首个NUL截断和分类优先级。两个实际分类函数分别注册为FL/FR入口，关闭时注销。

这里只完成分类与注册。AMF脚步事件、原地面材质名称、`foot_0/1/2`特效生成、声效播放及其运行时门控尚未接入；报告明确保留 `floor_effect_rendering_bound=false`。不能把分类成功视为特效或声音已播放。
