# 角色资源与动画

`pal4_portable_actor` 负责 CPU 骨架、蒙皮和动画采样，不依赖平台或 GPU。GLES 每帧只更新变形顶点，不重复创建贴图或程序。当前属于资源播放，尚未接入完整游戏动作控制器。

## 转换规则

DFF/ANM 读取器来自现有编辑器的只读解析代码，来源路径与哈希见文件头。DFF 转换保留流中的逆绑定矩阵，拒绝截断蒙皮和不支持的旧矩阵排列；ANM 读取逻辑未改变。

转换保留 Y 轴向上坐标、父子骨架、局部矩阵、预光照色、原始贴图行/UV、四权重蒙皮及关键帧。矩阵填充位转为仿射齐次值；重复骨架/逆绑定组合合并为调色板。三角形展开供当前 GLES 使用。

`hook_*` 保留骨架节点并隐藏辅助几何，尚不能代表武器或特效挂接。缺失纹理、无效索引、权重和动画映射会报错。

## P4AR v1/v2/v3/v4

全部小端，无对齐填充或本机指针。

| 内容 | 编码 |
| --- | --- |
| 文件头 | `P4AR`，随后 uint32：版本1、2或3、场景字节数、骨架数、调色板数、展开顶点数、动作数 |
| 网格 | 指定字节数的 P4SC v1 |
| 骨架节点 | int32 父索引（-1 或更早节点），16 个列主序 float32 仿射矩阵值 |
| 调色板项 | uint32 骨架索引，16 个 float32 逆绑定矩阵值 |
| 展开顶点蒙皮 | 4 个 uint32 调色板索引，4 个 float32 权重 |
| 动作 | uint32 ASCII 名称长度、名称字节、float32 时长、uint32 轨道数 |
| 轨道 | uint32 骨架索引、关键帧数，随后关键帧 |
| 关键帧 | 8 个 float32：时间、四元数 x/y/z/w、平移 x/y/z |
| v2尾部 | uint32 Atomic数量，随后每项 uint32 骨架索引＋4个float32原始首Morph包围球 x/y/z/r |
| v3材质 | 接在v2尾部之后：uint32材质数量，每项4个uint8原RGBA；相同内容的独立材质不合并 |
| v3几何 | uint32几何数量；每项uint32材质槽数量，随后对应数量的uint32材质索引，允许共享 |
| v3 Atomic | uint32数量（须等于包围球数量），每项uint32几何索引、原flags，沿用包围球顺序 |
| v3绘制映射 | uint32数量（须等于P4SC绘制批次数），每项uint32 Atomic索引、几何内材质槽索引 |

P4SC v1 的每条绘制记录在磁盘上固定为32字节；运行时 `Draw` 后续增加的UV动画字段不属于该记录，读取时须逐字段转换。

转换器现在生成v4，读取器兼容v1/v2/v3。包围球记录包含辅助和未绘制Atomic，按RenderWare遍历顺序保存：`RpClumpAddAtomic`（0x780440）插入链表头，`RpClumpForAllAtomics`（0x77FEF0）沿next访问，因此与DFF流顺序相反。绘制批次仍保留原转换顺序，通过显式索引定位Atomic。v1缺少包围球时不能用于250的查询范围；v1/v2的`render_bindings`为空，不能推测批次映射后用于距离插件。

v4在v3末尾追加原geometry顶点：uint32几何数（须等于材质映射的几何数），每项uint32顶点数及float3数组。保留所有原几何，包括隐藏挂点、非绘制Atomic和未绘制顶点；不从展开后的三角形反推。引用几何不能为空，非有限值、截断、计数/预算超限明确拒绝。已有v1/v2/v3仍可读取，但不能提供原顶点包围盒；不会默造默认包围盒。

材质列表沿用原解析器，修正其忽略共享引用表的行为：原SDK `0x78CC50`与`rpworld.lib`精确匹配，格式中-1消耗一个新Material块，非负索引引用此前槽位。解析结果保留同一对象身份；缺失/多余定义、向前或非法引用明确报错，取消用默认白材质补齐损坏列表。依据见`fresh/docs/third_party/renderware/ordered_78c920.md`；合成数据测试覆盖共享与同色独立材质。

`ActorBindSphere` 组合DFF初始骨架矩阵，复用 `AtomicPositionUpdater::ProcessBoundingSphere`（0x667C60）合并相对根节点的球。这里只覆盖初始姿态，未接动态包围球更新。4个玩家的原始球与缓存记录已逐位对照独立SDK null后端读取；合并结果仍有数值差异（本轮最大半径差约0.000485），原因和原游戏活动状态的数值等价尚未确认。

`ActorBindBox`复用原AtomicBoundingBoxBuilder::ProcessBoundingBox（667B70），按原Atomic顺序对完整几何顶点执行相对根节点的初始变换并累积最大/最小值。SceneMonsterInstances按模型只计算一次，并提供LocalBox与报告字段；不替代动态骨架包围更新或完整管理器初始化。

原401、402、405、407、408新缓存的逐Atomic原顶点位值与独立Win32 RenderWare SDK读取一致；初始包围盒6个分量在报告中完全一致。安卓原生CLI的5个包围盒及M01/1、M02/1共20只实例的完整报告也与主机一致；这不改变上文玩家球体的已知数值差异，也不证明完整游戏等价。证据在H:/PAL4/objs/pal4-android/actor-box-probe；新缓存置于该目录的独立cache，不覆盖已有已核验缓存或设备安装包。

读取器限制分配量，并拒绝非有限值、循环层级、重复名称/轨道、非单位四元数、不递增或不完整时间、无效蒙皮、截断及尾随数据。

采样按父子顺序组合矩阵，以 `frameWorld * inverseBind` 变形原顶点；旋转采用最短弧四元数插值，位移线性插值。采样函数及`ActorPlayback::Sample`可同时输出同一姿势的完整骨架矩阵，尚未乘场景实例变换；HOLD和混合均复用同一缓存，不另算一套姿势。动作-1使用DFF绑定姿态。预览默认循环采样；游戏播放器显式选择端点钳制，并由原插值时钟和AMF事件决定进度，见[玩家动作](PLAYER_ACTION.md)。已接入剧情转向结束的首姿势动画混合，见[逐帧转向](PLAYER_TURN.md)；面部、动态光照、阴影和武器服务仍未接通。

## 第120号服务的渲染前提

IDA核对`0x5D5620 → 0x663750`：`giCameraSetDistOptEnable`写8450引擎插件开关。`0x663470`以`0x663590`返回的原近似距离裁剪Atomic，在阈值内50单位修改全部几何材质RGBA；关闭时保留先前颜色并继续调用原绘制回调。因此不能只保存bool，也不能用整个模型的合并球代替逐Atomic中心。

已接公共`DistanceOptimization/AtomicDistanceInstance`，复用原`RwPlugin8450`处理器，读取同姿势矩阵并向GPU提交实际可见性和RGBA；引擎阈值复用原默认档位1（1200单位）。CPU实例跨EGL保持，BSP扇区不走此插件。边界及验证见[Atomic距离插件](ATOMIC_DISTANCE.md)。

## 验证与限制

101：134 骨架、133 调色板项、6944 三角形、127 次绘制；103：141 骨架、140 调色板项、7502 三角形、34 次绘制。绑定姿态最大坐标残差分别为 7.62939e-6、1.52588e-5；尚未独立对照原 SDK 动画采样输出。

CPU 测试覆盖独立骨架/逆绑定样例、90° 插值、反向四元数、循环、截断和非法数据。`verify-actors.ps1` 检查动作变化、切换、上下文恢复与场景往返。组合移动需准备原始 C01/C02/C03；独立预览默认 Z01/Z02。

v3补充共享几何/材质、隐藏Atomic映射、引用越界/数量/截断/尾随及同姿势矩阵测试；主机44/44、Python资源工具40/40、Android双ABI与Switch公共arena交叉编译通过。用户原Q01的37份模型重生成在`H:/PAL4/objs/pal4-android/prepared-data/render-bindings-v3/Q01/`，除版本号及新增尾部，旧缓存数据逐字节相同；加原201J共38份由C++读取并采样通过。报告`Q01-prefix-comparison.json`、`cpp-readback.json`位于该输出根；该目录是映射阶段的隔离证据。实际设备升级缓存改用`prepared-data/atomic-distance-runtime/`：Q01/N01共160份输入与用户原包逐项核对，四玩家从palactor.cpk重新提取；103旧103_2.png不符原包，已按原图重生成。设备最终验证见STATUS，原SDK动画数值等价仍开放。

## 原407权重兼容（2026-10-28）

原407.dff三条权重比1大一个float单位（0x3f800001），已从palactor.cpk核验SHA256一致。转换与ReadActor保留此位模式，校验有限/非负及原有总和0.002容差，移除单权重<=1的误拒绝。新增Python/C++用例检查位模式不变和明显超和失败；不修改蒙皮计算、不钳制或归一化。五个洞穴模型的安卓/主机采样只核验标量诊断，未声称原版变形或渲染等价。

本轮五个新缓存的旧内容（除版本字段）与v3前缀逐字节一致，仅追加原几何元数据；13项转换测试、主机5项回归及安卓3项合同通过。该比较不替代GPU画面或完整初始化验收。
