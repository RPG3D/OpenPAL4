# 怪物外层帧更新

AdvanceManagerAfterGrid已将原4317F0的活动/定时/追逐门控连接到实际移动行为事件调度器。原MonsterBehaviorManager::Update移到独立monster_behavior_manager_update.cpp供Win32与便携目标共用，分支与比较公式未另写。它不等于完整怪物管理器已经接通。

## 状态与服务

场景拥有者提供实际MonsterBehaviorManagerState、稳定数值token、elapsed/argument及IMonsterBehaviorFrameRuntime服务。这个服务的追逐处理、到期碰撞和基础位置更新均为必需接口，无空成功后备；SchedulerRuntime由移动拥有者替换为自己的实际队列调度器。

调用方拥有base、追逐、活动、定时等字段；+658处理器区由同一MonsterMovementBehavior独占。适配器在原调用前发布处理器视图，正常或异常后回收变更，保留候选数组进度和外层服务对处理器禁用标志的修改。不能由另一套事件拥有者同时写此区。

首次调用绑定借用图像与token，之后不得换地址或token；图像需比行为拥有者活得久，场景重载须重建拥有者。token受对齐/溢出检查，未将宿主指针编码为32位地址。网格阶段内禁止调用，单线程且不允许重入。每帧选择一个推进入口，不能再额外调用单轮或直接事件推进。

## 原调用顺序

- +1F0为零：不调用追逐、队列或基础位置服务。
- +730等于1：按原未舍入累加值比较+734；到期夹住+738、清模式、调用追逐碰撞。到期帧也不调事件队列；仍调用基础位置服务。
- 其他模式：先调用追逐状态服务，仅其返回0时调用原事件处理器，随后基础位置更新。返回基础位置服务的原结果。

异常可留下已更新计时、处理器、队列和动画状态，拥有者报错后不可继续推进；显式Cancel仍负责释放剩余helper。不是事务回滚。
