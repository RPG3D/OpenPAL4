# 基础对象成员的跨平台构造

原442450依次构造三个资源管理器、内嵌动画、四个效果句柄、两个字符串和碰撞角色。现将已有 Win32 成员适配逻辑提取为 BaseObjectMemberRuntime，继续调用相同原核心；NativeBaseObjectMemberRuntime 仅保留实际地址入口，删除重复成员实现。

## 身份与生命周期

调用方必须为每个 BaseObjectState 提供稳定、对齐且不溢出的32位逻辑身份，并提供实际内存、UV字典、动画、字符串和路径服务。成员适配器不截断64位宿主指针。字符串结构读写映射到调用方图像，两个32字节缓冲区仍由实际存储服务分配；路径哨兵也由实际服务拥有。身份空间与分配空间不得重叠。

原 BaseObjectLifecycle 负责顺序和异常逆序清理。成员适配器不负责整体对象所有权，不可对同一图像重复构造；销毁前依赖必须存活。原构造未写的字段仍保留输入值，不能把它当作全对象清零。

## 验证与限制

主机6项相关回归及安卓模拟器2项独立合同通过。新合同覆盖两个不同逻辑身份/图像、三个资源初值、原字符串缓冲区、真实内存表中的自链接路径哨兵、动画身份字节、三个分配阶段失败的逆序回收、非法身份与字符串越界。动画和字典服务在此为显式受控回调，不等于动态资源或真实动作装载已完成。Win32原有成员生命周期测试通过；Android双ABI公共库及Switch完整NRO构建通过。

原4312A0另有事件处理器、脚本对象、工厂表、战斗回调与后续状态；现另有[成员组合](MONSTER_OBJECT_MEMBERS.md)共用原构造入口。实际移动工厂和场景服务仍需接入该组合。非空怪物检查保留；未推进CSB剧情，第一章和战斗未完成。
