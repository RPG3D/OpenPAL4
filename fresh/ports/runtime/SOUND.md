# 原 CSB 二维音效

公共 `SoundServices` 处理服务 133/134/135，复用游戏侧 `ScriptSound2d`，不占用背景音乐或视频播放器。Android 的 `SoundTransport` 负责实际播放、生命周期和诊断；Switch 可消费同一命令接口，当前尚未接入实际播放。

## 原处理器语义

原入口 `0x5D58C0` 经 IDA 核对，归属分类为游戏侧待审查函数，复用已有重建处理器。

- 133 的正参数 N 表示总播放次数，0 表示无限循环；返回 -1，更新当前声音句柄。
- 负参数以循环模式 0 播放，并返回独立脚本 ID，从 0 起计。
- 133 不挂起脚本，也不自动停止之前的音效。
- 134 停止当前句柄；135 按脚本 ID 停止。

公共模块检查 WAV 容器边界并记录 PCM 元数据，使用 generation 与播放句柄拒绝过期通知。平台传回 prepared、started、paused、completed 或 failed；取消时释放所有播放器。这里不将未实现服务视为空操作继续。

## 用户原资源

开场读取用户目录 `gamedata/PALSound/WJ001.wav`，不修改原文件，不将它放入 APK。该文件独立于 CPK；脚本仍从用户原 `script.cpk` 装载。

当前原样本为 83580 字节、PCM 16 位、单声道、22050 Hz，data 为 83462 字节，对应 1.892562 秒。Android 通过内存 `MediaDataSource` 交给 MediaPlayer，不生成音效临时文件。模拟器独立探针已验证播放至自然结束；实际剧情中的调用尚待复测。输入 SHA256、轨道信息、播放位置和完成次数记入 `media-events.jsonl`；共享状态记入 `sound-probe.json`。

## 验证边界

主机测试覆盖原参数模式、非阻塞调用、重叠句柄、停止、过期事件、WAV 截断及脚本桥接。`verify-media.ps1` 使用用户原音效验证两次实际播放，并检查后台暂停时音效、淡入与脚本时钟同时冻结。模拟器解码和位置推进不能代替真机听音，也不代表完整章节或全部音效格式已经通过。
