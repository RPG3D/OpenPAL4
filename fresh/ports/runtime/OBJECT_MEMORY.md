# 跨平台对象存储

ObjectMemory 用标准容器持有字节块，为字符串、配置内存与原 CollisionActor 路径提供同一逻辑地址服务。它是32位游戏图像到现代宿主内存的适配层，不重写原堆或CRT算法，也不把宿主指针压成32位。

## 约束

每块按4字节分配逻辑身份，身份在存储生命周期内不复用。释放后访问、重复释放、块内指针释放、未对齐字访问和跨块读写明确失败。0字节请求拥有1字节实际存储，Free(0)返回0。新块清零是便携存储策略，不表示原HeapAlloc内容等价。

默认区间10000000～70000000，最多64 MiB实际字节和10万活跃块；可由场景拥有者指定预算。预算、活跃块数或身份区间耗尽会拒绝分配，不复用旧身份掩盖陈旧引用。调用方对象身份必须与分配区间分离。服务限同一线程，所有借用对象必须先于存储销毁。

## 已接入

SurfaceMotion 已删除私有节点表，改用本存储；默认路径身份仍从100000开始，24字节节点和原路径核心不变。共享存储入口可自行构造路径，也可借用已构造的空CollisionActor。Close只释放自己拥有的路径；借用模式只解除绑定，交回原对象统一销毁。定位失败仅销毁自行构造的成员，不释放借用成员。

基础对象成员合同也改用此实际存储，删除测试内另一份内存实现。两个基础对象的字符串/路径和一个SurfaceMotion共用存储，验证运动完成/关闭不释放其他对象，最终原生命周期清理到零分配。16/32/64字节预算分别触发第一字符串、第二字符串、路径哨兵分配失败，并验证原逆序清理。
